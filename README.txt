Danielle's HOTWORX Personal App

This is a private Progressive Web App (PWA).

To use it:
1. Upload this folder to any simple static web host such as GitHub Pages, Netlify, or Cloudflare Pages.
2. Open the resulting address in Safari on your iPhone.
3. Tap Share > Add to Home Screen.
4. The app will launch full-screen and save entries automatically on your device.

Important:
- Data is stored locally in Safari on that device.
- Use Export Backup periodically and before changing phones.
- Import Backup restores your records.
